## Lessons from these two days — do not repeat

1. **Promote: look again at the list in the last second.** A wait for the preview build let
   two other sessions' work ride along on a promote meant for one button. Use the exact
   commit you checked, not "the newest".
2. **A session that says "it asks you" is passing the work back.** The hub reads, decides the
   routine things, and brings him only real decisions.
3. **Do not report from a kind sample.** A 24-page check looked far better than the gold set.
4. **Say "not confirmed yet"** for a build still running, and check it next turn.
5. **Never name a student** in a report, and never a model in anything a student reads.
