# PAPER 2, QUESTION 5 of 10, 7 MARKS

The equation of a curve is $y = \frac{\sin x}{2 + \cos x}$, where $0 \le x \le 2\pi$.
(a) Find $\frac{dy}{dx}$, giving your answer in its simplest form. [3]
(b) Find the greatest and the least values of $\frac{dy}{dx}$ and the corresponding values of $x$. [4]

# SETTER'S ANSWER KEY
(a) $\frac{dy}{dx} = \frac{2\cos x + 1}{(2 + \cos x)^2}$
(b) Greatest value $\frac{1}{3}$, at $x = 0$ and $x = 2\pi$; least value $-1$, at $x = \pi$.

# SETTER'S WORKED SOLUTION
(a) Quotient rule, with $u = \sin x$, $v = 2 + \cos x$, $\frac{du}{dx} = \cos x$, $\frac{dv}{dx} = -\sin x$:
$\frac{dy}{dx} = \frac{\cos x\,(2 + \cos x) - \sin x\,(-\sin x)}{(2 + \cos x)^2} = \frac{2\cos x + \cos^2 x + \sin^2 x}{(2 + \cos x)^2}$   [M1]
Using $\sin^2 x + \cos^2 x = 1$:   [M1]
$\frac{dy}{dx} = \frac{2\cos x + 1}{(2 + \cos x)^2}$   [A1]

(b) Method 1 — differentiate again. With $u = 2\cos x + 1$, $v = (2 + \cos x)^2$, so $\frac{du}{dx} = -2\sin x$ and $\frac{dv}{dx} = 2(2 + \cos x)(-\sin x)$:
$\frac{d^2y}{dx^2} = \frac{-2\sin x\,(2 + \cos x)^2 + (2\cos x + 1)\,2\sin x\,(2 + \cos x)}{(2 + \cos x)^4}$   [M1]
$= \frac{2\sin x\left[-(2 + \cos x) + (2\cos x + 1)\right]}{(2 + \cos x)^3} = \frac{2\sin x\,(\cos x - 1)}{(2 + \cos x)^3}$   [A1]
$\frac{d^2y}{dx^2} = 0$ when $\sin x = 0$ or $\cos x = 1$, so in $0 \le x \le 2\pi$ the gradient turns only at $x = 0$, $x = \pi$ and $x = 2\pi$.   [M1]
$\cos x - 1 \le 0$ and $(2 + \cos x)^3 > 0$ for every $x$, so $\frac{d^2y}{dx^2}$ has the opposite sign to $\sin x$: the gradient falls on $0 < x < \pi$ and rises on $\pi < x < 2\pi$.
At $x = 0$: $\frac{dy}{dx} = \frac{2 + 1}{3^2} = \frac{1}{3}$. At $x = \pi$: $\frac{dy}{dx} = \frac{-2 + 1}{1^2} = -1$. At $x = 2\pi$: $\frac{dy}{dx} = \frac{1}{3}$.
Greatest value of $\frac{dy}{dx}$ is $\frac{1}{3}$, at $x = 0$ and at $x = 2\pi$; least value is $-1$, at $x = \pi$.   [A1]

Method 2 — treat the gradient as a function of $\cos x$. Write $c = \cos x$, so $\frac{dy}{dx} = \frac{2c + 1}{(2 + c)^2}$ with $-1 \le c \le 1$.   [M1]
$\frac{d}{dc}\left(\frac{2c + 1}{(2 + c)^2}\right) = \frac{2(2 + c)^2 - (2c + 1)\,2(2 + c)}{(2 + c)^4} = \frac{2 - 2c}{(2 + c)^3} \ge 0$ for $-1 \le c \le 1$,   [A1]
so the gradient increases with $c$ and takes its extreme values at the ends of the range of the cosine:   [M1]
at $c = 1$ (that is $x = 0$ and $x = 2\pi$) it is $\frac{3}{9} = \frac{1}{3}$, and at $c = -1$ (that is $x = \pi$) it is $\frac{-1}{1} = -1$.   [A1]

Mark scheme: (a) M1 quotient rule applied correctly; M1 $\sin^2 x + \cos^2 x = 1$ used to collapse the numerator; A1 $\frac{dy}{dx} = \frac{2\cos x + 1}{(2 + \cos x)^2}$.
(b) M1 differentiates $\frac{dy}{dx}$ again (quotient rule with the chain rule on $(2 + \cos x)^2$), or expresses the gradient as a function of $c = \cos x$; A1 $\frac{d^2y}{dx^2} = \frac{2\sin x\,(\cos x - 1)}{(2 + \cos x)^3}$ or any correct equivalent (Method 2: $\frac{2 - 2c}{(2 + c)^3}$ with its sign on $-1 \le c \le 1$ stated); M1 sets the derivative to zero and obtains the values of $x$ in $0 \le x \le 2\pi$ (or argues from the range of the cosine); A1 greatest $\frac{1}{3}$ at $x = 0$ and $x = 2\pi$ AND least $-1$ at $x = \pi$. The final A1 requires both extreme values with every value of $x$; omitting $x = 2\pi$ loses it. A candidate who states the two values with no supporting derivative scores at most M0A0M0A0.
Answers: (a) $\frac{dy}{dx} = \frac{2\cos x + 1}{(2 + \cos x)^2}$; (b) greatest $\frac{1}{3}$ at $x = 0$ and $x = 2\pi$, least $-1$ at $x = \pi$.
