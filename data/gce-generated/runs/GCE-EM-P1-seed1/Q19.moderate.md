# PAPER 1, QUESTION 19 of 27, 3 MARKS

A teacher has 216 pens and 288 erasers. She puts them into gift bags so that each bag has the same number of pens and the same number of erasers, with none left over.
(a) Find the greatest number of gift bags she can make. [2]
(b) She also puts stickers into each of the gift bags, with the same number in each bag and none left over. Stickers are sold in packets of 10.
Find the smallest number of packets of stickers she must buy. [1]

# SETTER'S ANSWER KEY
(a) 72
(b) 36 packets (360 stickers)

# SETTER'S WORKED SOLUTION
(a) The number of bags must divide both 216 and 288 exactly, so the greatest number of bags is the HCF of 216 and 288.
$216 = 2^3 \times 3^3$
$288 = 2^5 \times 3^2$
HCF $= 2^3 \times 3^2 = 72$
Greatest number of gift bags $= 72$.
(Each bag then has $216 \div 72 = 3$ pens and $288 \div 72 = 4$ erasers.)

(b) The stickers come in packets of 10, so the number bought is a multiple of 10. They are shared equally among 72 bags with none left over, so the number is also a multiple of 72.
Smallest number $=$ LCM of 10 and 72 $= 2^3 \times 3^2 \times 5 = 360$.
(That is 36 packets, giving $360 \div 72 = 5$ stickers in each bag.)

(b) The number of stickers must be a multiple of 72 and of 10. LCM(72, 10) = 360, so she buys 360 stickers = 36 packets.
