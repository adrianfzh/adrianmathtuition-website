# PAPER 1, QUESTION 8 of 27, 3 MARKS

It is given that $(x + 2)(x^2 + hx + k) = x^3 - x^2 - 10x - 8$ for all values of $x$.
(a) Find the value of $h$ and the value of $k$. [2]
(b) Hence factorise $x^3 - x^2 - 10x - 8$ completely. [1]

# SETTER'S ANSWER KEY
(a) $h = -3$, $k = -4$
(b) $(x + 2)(x + 1)(x - 4)$

# SETTER'S WORKED SOLUTION
Expand the left-hand side:
$(x + 2)(x^2 + hx + k) = x^3 + hx^2 + kx + 2x^2 + 2hx + 2k = x^3 + (h + 2)x^2 + (k + 2h)x + 2k$.

(a) Comparing the coefficients of $x^2$: $h + 2 = -1$, so $h = -3$.
Comparing the constant terms: $2k = -8$, so $k = -4$.
(Check with the coefficient of $x$: $k + 2h = -4 - 6 = -10$, which agrees.)

(b) From (a), $x^3 - x^2 - 10x - 8 = (x + 2)(x^2 - 3x - 4)$.
$x^2 - 3x - 4 = (x + 1)(x - 4)$, so
$x^3 - x^2 - 10x - 8 = (x + 2)(x + 1)(x - 4)$.
