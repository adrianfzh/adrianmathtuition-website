# PAPER 1, QUESTION 27 of 27, 6 MARKS

The first five terms of a sequence are $5$, $12$, $21$, $32$, $45$.
(a) Write down the next term of the sequence. [1]
(b) Find an expression, in terms of $n$, for the $n$th term of the sequence. [2]
(c)  [3]
  (i) Show that every term of the sequence is 4 less than a square number. [1]
  (ii) Hence explain why 500 is not a term of the sequence. [1]
  (iii) Hence find the value of $n$ for which the $n$th term of the sequence is 1152. [1]

# SETTER'S ANSWER KEY
(a) $60$
(b) $n^2 + 4n$
(c)(i) $n^2 + 4n = (n+2)^2 - 4$, and $(n+2)^2$ is a square number
(c)(ii) $500 + 4 = 504$ is not a square number ($22^2 = 484$, $23^2 = 529$)
(c)(iii) $n = 32$

# SETTER'S WORKED SOLUTION
(a) The differences between consecutive terms are $7, 9, 11, 13$, so the next difference is $15$.
Next term $= 45 + 15 = 60$.

(b) The second difference is constant, $2$, so the $n$th term is $n^2 + bn + c$.
$n = 1$: $1 + b + c = 5$; $n = 2$: $4 + 2b + c = 12$.
Subtracting, $3 + b = 7$, so $b = 4$ and $c = 0$.
$n$th term $= n^2 + 4n$ (which is $n(n+4)$). Check: $n = 5$ gives $25 + 20 = 45$.

(c)(i) $n^2 + 4n = (n+2)^2 - 4$.
$(n+2)^2$ is a square number, so every term is 4 less than a square number.

(c)(ii) If 500 were a term, then $500 + 4 = 504$ would be a square number.
$22^2 = 484$ and $23^2 = 529$, so $504$ is not a square number. Hence 500 is not a term of the sequence.

(c)(iii) $1152 + 4 = 1156 = 34^2$.
So $(n+2)^2 = 34^2$, giving $n + 2 = 34$ and $n = 32$.
Check: $32^2 + 4 \times 32 = 1024 + 128 = 1152$.
