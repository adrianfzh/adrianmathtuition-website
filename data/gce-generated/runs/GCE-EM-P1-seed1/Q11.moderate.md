(a) $\frac{2(x + 2)}{x - 3}$

# SETTER'S WORKED SOLUTION
(a) Factorise the numerator: $2x^2 - 8 = 2(x^2 - 4) = 2(x - 2)(x + 2)$.
Factorise the denominator: $x^2 - 5x + 6 = (x - 2)(x - 3)$.
So $\frac{2x^2 - 8}{x^2 - 5x + 6} = \frac{2(x - 2)(x + 2)}{(x - 2)(x - 3)} = \frac{2(x + 2)}{x - 3}$.

(b) Using (a), $\frac{2(x + 2)}{x - 3} = 4$
$2x + 4 = 4x - 12$
$16 = 2x$
$x = 8$.
Check: $\frac{2(64) - 8}{64 - 40 + 6} = \frac{120}{30} = 4$.
