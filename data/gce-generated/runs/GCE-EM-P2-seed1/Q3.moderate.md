# SETTER'S ANSWER KEY
(a) $a = -1$, $b = 2$, $c = 3$
(b)(i) $4 - (x - 1)^2$
(b)(ii) $(1, 4)$
(c) $y = -3x + 7$

# SETTER'S WORKED SOLUTION
(a) Since the curve crosses the $x$-axis at $x = -1$ and $x = 3$, its equation can be written as $y = a(x + 1)(x - 3)$.
The curve passes through $(0, 3)$: $3 = a(0 + 1)(0 - 3) = -3a$, so $a = -1$.
Expanding, $y = -(x + 1)(x - 3) = -(x^2 - 2x - 3) = -x^2 + 2x + 3$.
Hence $a = -1$, $b = 2$, $c = 3$.

(b)(i) $-x^2 + 2x + 3 = -(x^2 - 2x) + 3 = -\left[(x - 1)^2 - 1\right] + 3 = -(x - 1)^2 + 1 + 3 = 4 - (x - 1)^2$.
So $k = 4$ and $h = 1$.

(b)(ii) Since $(x - 1)^2 \ge 0$, the greatest value of $y$ is $4$, occurring when $x = 1$.
The maximum point is $(1, 4)$.

(c) When $x = 4$: $y = -(4)^2 + 2(4) + 3 = -16 + 8 + 3 = -5$, so $P$ is $(4, -5)$.
Gradient of the line through $P(4, -5)$ and the maximum point $(1, 4)$: $\frac{4 - (-5)}{1 - 4} = \frac{9}{-3} = -3$.
Using the point $(1, 4)$: $y - 4 = -3(x - 1)$, so $y = -3x + 7$.
Check at $P$: $-3(4) + 7 = -5$. Correct.
The equation of the line is $y = -3x + 7$.
