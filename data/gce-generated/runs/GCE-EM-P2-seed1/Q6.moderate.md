# SETTER'S WORKED SOLUTION
(a) Gradient of $AB = \frac{7 - (-1)}{2 - (-4)} = \frac{8}{6} = \frac{4}{3}$
The required line is parallel to $AB$, so its gradient is also $\frac{4}{3}$, and it passes through $C(10,\,-1)$:
$y - (-1) = \frac{4}{3}(x - 10)$
$3(y + 1) = 4(x - 10)$
$3y + 3 = 4x - 40$
$4x - 3y = 43$
Check with $C$: $4(10) - 3(-1) = 40 + 3 = 43$.

(b) $AB = \sqrt{(2 - (-4))^{2} + (7 - (-1))^{2}} = \sqrt{6^{2} + 8^{2}} = \sqrt{36 + 64} = \sqrt{100} = 10$ units

(c) $A(-4,\,-1)$ and $C(10,\,-1)$ have the same $y$-coordinate, so $AC$ is horizontal.
Base $AC = 10 - (-4) = 14$ units.
The perpendicular height from $B$ to $AC$ is $7 - (-1) = 8$ units.
Area of triangle $ABC = \frac{1}{2} \times 14 \times 8 = 56$ units$^2$

(d)(i) $\overrightarrow{PQ} = \overrightarrow{OQ} - \overrightarrow{OP} = \mathbf{q} - \mathbf{p}$
Since $PR : RQ = 1 : 2$, $\overrightarrow{PR} = \frac{1}{3}\overrightarrow{PQ} = \frac{1}{3}(\mathbf{q} - \mathbf{p})$
$\overrightarrow{OR} = \overrightarrow{OP} + \overrightarrow{PR} = \mathbf{p} + \frac{1}{3}\mathbf{q} - \frac{1}{3}\mathbf{p} = \frac{2}{3}\mathbf{p} + \frac{1}{3}\mathbf{q}$

(d)(ii) Since $OS : SQ = 1 : 2$, $\overrightarrow{OS} = \frac{1}{3}\mathbf{q}$
$\overrightarrow{SR} = \overrightarrow{OR} - \overrightarrow{OS} = \frac{2}{3}\mathbf{p} + \frac{1}{3}\mathbf{q} - \frac{1}{3}\mathbf{q} = \frac{2}{3}\mathbf{p}$

(d)(iii) $\overrightarrow{SR} = \frac{2}{3}\overrightarrow{OP}$, so $SR$ is parallel to $OP$ and $SR = \frac{2}{3}OP$.
Triangles $QSR$ and $QOP$ share the angle at $Q$, and angle $QSR = $ angle $QOP$ (corresponding angles, $SR \parallel OP$), so the triangles are similar with $\frac{SR}{OP} = \frac{2}{3}$.
$\frac{\text{area of triangle } QSR}{\text{area of triangle } QOP} = \left(\frac{2}{3}\right)^{2} = \frac{4}{9}$
Check by common heights: triangles $QSR$ and $QOR$ have the common vertex $R$ with bases $QS$ and $QO$ on the same line, so $\frac{\text{area } QSR}{\text{area } QOR} = \frac{QS}{QO} = \frac{2}{3}$; triangles $QOR$ and $QOP$ have the common vertex $O$ with bases $QR$ and $QP$ on the same line, so $\frac{\text{area } QOR}{\text{area } QOP} = \frac{QR}{QP} = \frac{2}{3}$. Hence $\frac{\text{area } QSR}{\text{area } QOP} = \frac{2}{3} \times \frac{2}{3} = \frac{4}{9}$, as before.
